# Geo Agent Skills

This package is the source of truth for Geo App agent playbooks. These skills
teach user-owned agents how to use the `geo` CLI safely and consistently.

The first-phase skill set is:

- `geo-shared`
- `geo-prompt-ops`
- `geo-run-analysis`
- `geo-reporting`
- `geo-skill-execution`
- `geo-competitor-citation-analysis`

Install through the CLI:

```bash
geo agent-skills install --agent codex
geo agent-skills install --agent claude
geo agent-skills doctor --agent codex
```
