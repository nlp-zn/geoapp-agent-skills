# Geo Agent Skills Examples

These examples are prompts you can give to a user-owned agent after installing
the Geo agent skills.

Each example shows:

- which skills should trigger
- which commands the agent should prefer
- what safety gates apply
- what output the user should receive

## Examples

| Example | Primary Skills |
| --- | --- |
| `prompt-batch-run-report.md` | `geo-shared`, `geo-prompt-ops`, `geo-run-analysis`, `geo-reporting` |
| `competitor-citation-gap.md` | `geo-shared`, `geo-competitor-citation-analysis`, `geo-run-analysis`, `geo-reporting` |
| `run-failure-triage.md` | `geo-shared`, `geo-run-analysis` |
| `server-skill-execution.md` | `geo-shared`, `geo-skill-execution`, `geo-reporting` |

Run `geo doctor`, `geo auth status`, and `geo brand current` before adapting any
example to a real account.
